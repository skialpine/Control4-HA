# Source provenance

This project builds on the Home Assistant drivers by BP / bphillips09 and uses
Finite Labs' Control4 Driver Template v0.9.116 under AGPL-3.0.
[Finite Labs template](https://github.com/finitelabs/control4-driver-template/tree/v0.9.116)

The vendored libraries retain their original notices. Control4's
`drivers-common-public` supplies shared DriverWorks helpers. The source and
packages include the xml2lua MIT license. JSON.lua retains Jeffrey Friedl's
attribution. See the [source inventory](../provenance/sources.json) for the
pinned sources and [NOTICE](../NOTICE) for credits.
