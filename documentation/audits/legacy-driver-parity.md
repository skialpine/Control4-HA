# Legacy driver task parity

The 29 legacy packages inspected declare a later build. The inventory comes
from package XML and the installation manual. XML establishes which controls,
connections and events the packages declare. Verify runtime and saved-project
behavior on the installed baseline and replacement.

The local notification workflow also covers connection loss and recovery, binary
sensor transitions, and alarm arming, disarming, alarm and unavailable states.
Verify a supported Control4 notification route, including recipient settings and
duplicate suppression, without requiring the installer to rebuild every trigger.

Exercise each replacement against a project containing the legacy drivers. Start
by reviewing the selected endpoint, settings, room, connections, scene
memberships and Programming. Verify exact readback and state feedback before
handing off control. Confirm the old references still work after a failed
transfer or explicit rollback. Keep live security and motion operations on
approved test fixtures.
