# Home Assistant for Control4

The Coordinator connects Home Assistant to the Light and Switch drivers. The
current packages are development builds for the isolated lab. Setup, power,
brightness and supported color controls are undergoing qualification. See the
[installation guide](installation.md), [device setup guide](device-setup.md) and
[selected-device commissioning guide](commissioning-contract.md).

The suite uses Finite Labs' pinned template. See
[source provenance](provenance.md) for BP / bphillips09 credit, vendor notices
and public distribution gates. Source:
<https://github.com/skialpine/Control4-HA>.

Other device families remain a roadmap following initial Light/Switch feedback.
See the [release readiness checklist](release-readiness.md) for the evidence
required for feedback and general availability.
