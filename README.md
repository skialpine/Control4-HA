# Home Assistant for Control4

The Home Assistant Connection links Home Assistant to Control4. The Light driver
supports on/off, dimming and color where the device provides them. The Switch
driver controls on/off equipment. The optional HA Gesture Bridge adds device
discovery, button presses and indicators for supported hardware.

GitHub prereleases are development builds for testing. Use the three driver
packages from the same revision and follow the installer instructions for your
starting driver. Keep a Control4 project backup before updating.
