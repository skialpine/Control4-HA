# Home Assistant Media Player

Choose a player in Device Setup. In Composer, assign the player's **Room Audio**
connection for room selection or connect its audio or HDMI output to the
corresponding input in the room's audio path.

Open the room's media controls for playback and Now Playing information. The
transport controls reflect the selected player's capabilities. Volume, mute,
shuffle and repeat depend on support from the player. Use **Select Source** in
Programming with a source name from the selected player in Home Assistant.

Use **Quick Setup** on the Home Assistant Connection to add the driver in a
room. Check the room's media controls after assigning the audio connections.
[Installation and troubleshooting](https://github.com/skialpine/Control4-HA/blob/main/documentation/installation.md)
