# Home Assistant Alarm Panel

Choose an alarm in Device Setup and assign its security partition to the desired
room in Composer. Use the room's security controls to arm or disarm the alarm.
Enter your code at the Control4 prompt if your panel requires one. The alarm
reports its supported arm modes in Control4 Programming.

Control4 displays the state reported by Home Assistant, including arming, armed,
disarmed, entry delay, and triggered.

Use **Quick Setup** on the Home Assistant Connection to add the driver in a
room. The installer verifies room selection and the code prompt using a test
panel before configuring a live alarm.
[Installation and troubleshooting](https://github.com/skialpine/Control4-HA/blob/main/documentation/installation.md)
